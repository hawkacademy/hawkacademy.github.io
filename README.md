# Hawk Academy: ОГЭ-2027 — сайт

Сайт тренажёра ОГЭ-2027 для iPhone: https://hawkacademy.github.io/

- `index.html` — главная
- `support.html` — поддержка (Support URL для App Store)
- `privacy.html` — политика конфиденциальности (Privacy Policy URL для App Store)
